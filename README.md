# Homebrew Tap for Voice2Text

## Install

```bash
brew tap thobai/voice2text
brew install voice2text
```

## What is Voice2Text?

A native macOS push-to-talk voice transcription app. Hold Right Command to record, release to transcribe and paste. Runs entirely locally using whisper.cpp and MLX.

See [thobai/voice2text](https://github.com/thobai/voice2text) for details.
